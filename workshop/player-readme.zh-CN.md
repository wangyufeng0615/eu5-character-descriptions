# 所有历史人物的描述

为《欧陆风云5》7,789 位历史人物提供英文和简体中文生平。鼠标停在人物头像上，生平在浮窗最下方。按游戏语言显示英文或中文。

手动安装：把发布的 ZIP 解压到 `文档\Paradox Interactive\Europa Universalis V\mod\`，得到 `mod\character_descriptions\`（保留隐藏的 `.metadata` 文件夹），然后在“模组和 DLC”里启用。不要同时启用手动副本和工坊副本。

生平由 AI 辅助、依据公开资料（主要是维基百科）写成，与游戏人物逐一对上，并逐条审阅过。发现错误欢迎在工坊留言。正文用 CC BY-SA 4.0，工具用 MIT，见 LICENSE 和 CREDITS.md；每个人物的资料来源在 `sources/sources.jsonl`。
